# RainwaterHarvestingfrontend

Responsive React + Bootstrap frontend for the Rainwater Harvesting Unit API.

## Run locally

1. Start the Spring Boot backend on port `9000`.
2. Install dependencies and start the frontend:

```bash
npm install
npm run dev
```

The Vite development server proxies `/Harvestingunit` requests to `http://localhost:9000`.

For a deployed backend, set `VITE_API_BASE_URL` before building:

```bash
VITE_API_BASE_URL=https://your-api-host npm run build
```

The add form intentionally omits the database ID. IDs are generated by the backend.
